Administrative Reset & Purge Governance

These operations permanently modify MongoDB Atlas collections (expenses, pool_deposits, members). Please verify before executing.

1. Reset Ledger Expenses

Deletes all bill entries from the expenses MongoDB collection. Roommates and deposit balances remain intact.

2. Reset Room Deposits

Clears the pool_deposits collection and resets all roommate deposited amounts back to ₹0.

3. Complete Factory Reset

Restores initial default roommates, clears all expenses and deposits, and restores default room configuration.
